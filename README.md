Language Dungeon — Egypt × Japan 🇪🇬🇯🇵

A browser-based 3D language and culture puzzle game built for the E-JUST Summer Program 2026 cultural exchange days, bringing together ancient Egyptian and Japanese mythology, language, and history in one interactive dungeon.

About the Project

Language Dungeon invites players to walk through a 3D sanctuary that merges Egyptian and Japanese heritage. Each of the 15 stages is themed around a real deity or historical figure from either culture, and unlocking the path forward means solving a puzzle tied to that culture's language, mythology, or history.

This project was created by Omar Mahmoud Ismail as part of a cultural exchange activity during E-JUST's Summer Program 2026, where students from Japan, South Korea, South Africa, Vietnam, China, and Russia visited our campus. It was presented alongside a companion presentation, put together with a team, as part of the day's cultural exchange activities.

Features
15 unique stages, alternating between Egyptian, Japanese, and fusion-themed rooms
First-person 3D exploration built with Three.js, with full desktop and mobile controls
A variety of puzzle types, including:
Hieroglyph decoding
Hiragana matching
Lever and pressure-plate sequences
Symbol rotation
Memory sequences
Cultural riddles
Hidden object search
Light-reflection puzzles
Fully procedural audio — no external sound files, everything is generated in-browser
Real figures, real history — each room includes a short blurb on the deity or historical figure it's themed around (e.g. Tutankhamun, Ra, Isis, Amaterasu, Susanoo, Inari)
How to Play
Open the game link
Enter your name to begin
Move with WASD, look with the mouse, Shift to sprint, Space to jump
Press E to interact with objects, levers, and puzzle doors
Solve each stage's puzzle to progress deeper into the dungeon
Reach the end to see your final score

On mobile, use the on-screen joystick and buttons.

Tech Stack
Three.js (r128) for 3D rendering
Vanilla JavaScript for game logic and puzzle systems
Web Audio API for fully procedural sound design
HTML/CSS for UI, HUD, and menus
